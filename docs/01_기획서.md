- 작성: 2026-11-16 · 팀: J, 지호 (오시마켓에 이은 같은 멤버의 두 번째 프로젝트)
- 상태: 기획 단계 · 개발 시작은 **2026-11-30 이후**
- 이름: **Feynote** = 파인만(Feynman) + 노트. 파인만 학습법은 "쉬운 내 말로 설명할 수 있어야 진짜 이해한 것"이라는 공부법이다.

---

## 1. 한 줄 소개

**논문을 읽고 싶지만 허들이 있는 개발자를 위해, AI가 질문하고 내가 답하면서 내 말로 요약을 완성하게 돕는 서비스**

- 키워드: **LLM 백엔드**

## 2. 왜 만드나

- 직접 논문을 읽어 보니 두 군데가 무거웠다.
  1. **시작:** 내용보다 "논문을 읽는다"는 이름 자체가 부담이다.
  2. **정리:** 문답은 따라가지만, 마지막에 **내 말로 두세 줄 요약**하는 게 어렵다.
- 기존 서비스(예: 라이너 스칼라)는 **AI가 대신 요약**해 준다. 빨리 파악하기엔 좋지만 내 것으로 남지 않는다.
- 우리는 **AI가 대신 읽어 주는 도구가 아니라, 내가 이해하고 체화하게 돕는 도구**로 차별화한다.

## 3. 대상과 범위

| 항목 | 내용 |
|---|---|
| 대상 | 논문을 읽고 싶은 개발 취준생·주니어 개발자 |
| 읽을거리 | 논문부터 시작 → 기술 블로그로 확장 |
| 분야 | 개발·AI부터 시작 (세무·경제 등 확장은 논의 중) |

## 4. 핵심 흐름

```
논문 업로드
  → 5분 분량 조각으로 나눔 (시작 허들 낮추기)
  → AI가 조각마다 질문
  → 내가 답함
  → 내 답을 모아 요약 초안 제시 ("쓰기"가 아니라 "고치기")
  → 내가 고쳐서 요약 완성
  → 확인 질문 통과 시 "설명할 수 있음"
```

**실제 사례 (Attention Is All You Need)**
- 처음 쓴 문장: "트랜스포머로 번역한 문장들은 비약적으로 (기존 대비 몇 퍼센트?) 상승했으며…"
- 고친 문장: "영어→독일어 번역 점수(BLEU)는 기존 최고 기록보다 2점 이상(약 8%) 올랐고, 영어→프랑스어도 기존의 4분의 1도 안 되는 학습 비용으로 최고 기록을 냈다."
- 확인 질문 3개 통과 → 이 과정을 서비스로 만든다.

## 5. 기술과 딥다운 주제

- 스택: Java · Spring Boot · PostgreSQL · Docker + LLM
- 기본 CRUD와 프론트는 Claude Code를 활용하고, 각자 기능 하나를 깊게 판다.

| 담당 | 딥다운 주제 | 한 줄 설명 |
|---|---|---|
| J | **LLM 작업 처리 흐름** | 느리고 가끔 실패하는 LLM 요청을 비동기 처리·재시도·캐싱으로 **안정적으로** 처리 |
| 지호 | **답변 일관성·품질 관리** | 질문이 달라도 답변이 사용자 수준에 맞춰 **일관된 형식과 품질**로 나오게 (형식 검사, 수준 맞춤, 프롬프트 버전 관리) |
