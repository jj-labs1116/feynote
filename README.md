# Feynote

> 내 말로 요약하게 돕는 논문 이해 AI 서비스

논문을 읽고 싶지만 허들이 있는 개발자를 위해, **AI가 질문하고 내가 답하면서 내 말로 요약을 완성하게 돕는 서비스**입니다.

이름은 파인만(Feynman) + 노트(note)에서 따왔습니다. 파인만 학습법은 "쉬운 내 말로 설명할 수 있어야 진짜 이해한 것"이라는 공부법입니다.

## 왜 만드나

- 논문은 "논문을 읽는다"는 이름 자체가 부담이라 **시작이 무겁고**, 다 읽어도 **내 말로 정리하기가 어렵습니다.**
- 기존 서비스는 AI가 대신 요약해 줍니다. 빨리 파악하기엔 좋지만 내 것으로 남지 않습니다.
- Feynote는 AI가 대신 읽어 주는 도구가 아니라, **내가 이해하고 체화하게 돕는 도구**입니다.

## 핵심 흐름

```
논문 업로드
  → 5분 분량 조각으로 나눔
  → AI가 조각마다 질문
  → 내가 답함
  → 내 답을 모아 요약 초안 제시
  → 내가 고쳐서 요약 완성
  → 확인 질문 통과 시 "설명할 수 있음"
```

## 기술 스택

- Backend: Java 17, Spring Boot
- Database: PostgreSQL
- Infra: Docker
- AI: LLM (모델 선정 중)
